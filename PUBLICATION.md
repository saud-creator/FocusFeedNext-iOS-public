# Public source provenance

Public source: https://github.com/saud-creator/FocusFeedNext-iOS-public

This independent repository preserves six branches and their sanitized history.
The original development repository remains private. Do not merge or push its
old history here: that would reintroduce personal information.

Personal machine paths and two screenshots containing those paths have been
removed from source documents and nested archives throughout this history.
Commit identities use GitHub noreply email addresses. Historical checksums and
commit references in older notes describe the original private builds;
sanitized source archives have different checksums. Old development links may
require access to the private repository.

The public main branch starts from the audited 0.9.0 development snapshot.
Uncommitted app-development work is not included. Application implementation
files were not changed by the publication cleanup.

See SECURITY.md for ongoing privacy checks. Automated scans complement visual
and GitHub-surface review; they are not a full runtime security certification.
